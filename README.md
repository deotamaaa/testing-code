# One More Reps 🏋️

A lightweight **gym and calorie tracker** built as a static web app — no backend,
no build step. All your data is stored locally in your browser.

## Features

- **Gym Log** — record exercises with sets, reps, weight, and date.
- **Calories** — log meals with their calorie counts and date.
- **Progress** — at-a-glance stats (workouts logged, calories today, active days)
  plus a 7-day calorie bar chart.

## Notes

Data is stored per-browser and per-device, so entries do not sync across devices.
